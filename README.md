
# 💼 Ma Personne Professionnelle

## 📖 Description

**Ma Personne Professionnelle** est un **portfolio interactif web personnel** et un **curriculum vitae en ligne**  développé en **HTML**, **CSS** et **JavaScript**.

Ce site a pour objectif de présenter mon parcours professionnel, mes compétences, mes certifications et mon curriculum vitae dans une interface moderne, responsive et accessible en ligne.

Au-delà de l'aspect portfolio, ce projet me permet de mettre en pratique les bonnes pratiques du développement logiciel et du DevOps, notamment la conteneurisation avec Docker, l'intégration continue (CI), le déploiement continu (CD) et l'automatisation avec GitHub Actions.

---

## 🎯 Objectifs

- Présenter mon profil professionnel.
- Mettre à disposition mon CV en ligne.
- Valoriser mes certifications.
- Faciliter le contact avec les recruteurs.
- Construire un portfolio moderne et responsive.
- Appliquer les bonnes pratiques du développement et du DevOps.

---

## ✨ Fonctionnalités

Le site comprend les sections suivantes :

- 🏠 **Home**
- 📄 **Mon CV**
- 📜 **Mes Certifications**
- 🌐 **Mes Réseaux sociaux**

La page **Home** est la page affichée par défaut.

## 🚀 Installation

### Cloner le projet

```bash
git clone https://github.com/Chrystal-dev/Ma-Perso-Pro.git
```

Accéder au projet :

```bash
cd Ma-Perso-Pro
```

---

## 🐳 Exécution avec Docker

Construire l'image Docker :

```bash
docker build -t ma-perso-pro .
```

Lancer le conteneur :

```bash
docker compose up
```

Le site sera accessible à l'adresse :

```
https://chrystal-dev.github.io/Ma-Perso-Pro/
```
